# Backlinks2026

Working files for the KA Talent Partners website (design version 02).

KA Talent Partners is an education recruitment firm. It connects teachers with schools across Victoria and New South Wales, Australia.

## What's here

- `KA-Design-02.zip` – the original upload, kept as-is.
- `KA-Design-02/` – the unzipped site.
  - 7 pages: `index.html`, `about.html`, `for-teachers.html`, `for-schools.html`, `team.html`, `contact.html`, `privacy-policy.html`
  - `assets/css`, `assets/js`, `assets/img`, `assets/vendor` (Bootstrap, Bootstrap Icons, local fonts)
  - `START-HERE.txt` and `IMAGE-NOTES.txt` – notes from the design export
  - `preview-desktop.jpg`, `preview-hero.jpg` – full-page screenshots

## View it

Open `KA-Design-02/index.html` in a browser. All files are local.
